### 13.2.3 은행이 사랑한 HSM
하드웨어 보안 모듈<sub> ( HSM, hardware security module )</sub>은 FIPS 140-2, '<font color="#00b0f0">암호화 모듈에 대한 보안 요구 사항</font>'에 따라 분류된다. 이 문서는 2001년에 게시된 꽤 오래된 문서며, 당연히 게시 이후에 발견된 여러 공격을 고려하지 않았다. 다행히 2019년에는 보다 현대적인 버전인 FIPS 140-3으로 대체되었다. 

<font color="#de7802">FIPS 140-3</font>은 이제 <font color="#00b0f0">두 가지 국제 표준에 의존</font>한다.
( 두 표준은 무료가 아니다. 읽으려면 비용을 지불해야 한다. )

- **ISO/IEC 19790:2012**: 하드웨어 보안 모듈에 대한 <font color="#00b0f0">4 가지 보안 수준을 정의</font>한다.
	- 레벨 1 HSM: 물리적 공격에 대한 보호 기능을 제공하지 않는다. ( 순수한 S/W 구현으로 생각할 수 있다. )
	- 레벨 3 HSM: 침입을 감지하면 비밀을 삭제한다.
	  
- **ISO 24759:2017**: HSM 제품에 대한 인증을 표준화하기 위해 <font color="#00b0f0">HSM 을 테스트하는 방법을 정의</font>한다.

미국, 캐나다 및 기타 일부 국가에서는 은행과 같은 특정 산업에서 FIPS 140 수준에 따라 인증된 장치를 사용하도록 의무화하고 있다.

>[!NOTE] 
> 비밀을 지우는 것은 제로화라고 부르는 관행이다.
> 레벨 3 HSM 과 달리 레벨 4 HSM 에는 내부 백업 배터리가 있으므로 정전 시에도 비밀 데이터를 여러 번 덮어쓸 수 있다. 

일반적으로 HSM 은 데이터 센터의 엔터프라이즈 서버에 연결된 랙의 외부 장치로서 서버의 마더보드에 연결된 PCIe 카드, 또는 하드웨어 보안 토큰과 유사한 작은 동글의 형태로 발견할 수 있다.
