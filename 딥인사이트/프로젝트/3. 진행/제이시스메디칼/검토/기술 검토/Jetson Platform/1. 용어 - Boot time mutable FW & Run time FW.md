# NVIDIA Jetson Orin 부팅 펌웨어 분석

## 1. 용어의 배경: Immutable(불변) vs Mutable(가변)
NVIDIA Tegra/Orin 보안 및 부팅 아키텍처에서 펌웨어는 수정 가능 여부에 따라 다음과 같이 구분됩니다.
*   **Immutable ROM (불변 코드)**: 실리콘 하드웨어에 마스크 롬 형태로 고정 배선되어 출하 후 절대 수정할 수 없는 코드입니다. (예: **BootROM**, **PSCROM**)
*   **Mutable FW (가변/업데이트 가능 펌웨어)**: QSPI-NOR 또는 eMMC 파티션에 저장되며, 서명 검증을 거쳐 필드에서 OTA(Over-The-Air)나 플래싱 툴을 통해 업데이트할 수 있는 바이너리입니다.

> **참고**: Cold Boot Sequence 다이어그램은 이 Mutable FW를 동작 시점과 생명주기(Lifecycle)에 따라 **'Boot time'**과 **'Run time'** 두 가지 범주로 분리하여 도식화하고 있습니다 (추측).
---

## 2. 'Boot time mutable FW' vs 'Run time FW' 비교 분석
| 비교 항목        | Boot time mutable FW                               | Run time FW                                            |
| :----------- | :------------------------------------------------- | :----------------------------------------------------- |
| **실행 생명주기**  | **부팅 단계 한정 (Transient)**<br>초기화 완료 후 종료/폐기         | **OS 구동 내내 상주 (Resident)**<br>시스템 파워오프 시까지 상시 동작       |
| **주요 컴포넌트**  | MB1, MB2, Applet, 초기화 BCT                          | BPMP-FW, PSC-FW, MCE-FW, ATF(BL31), OP-TEE(BL32)       |
| **실행 프로세서**  | BPMP (MB1 실행 시), CCPLEX (MB2 실행 시)                 | BPMP, PSC, CCPLEX(MCE/EL3/Secure-EL1)                  |
| **시스템 권한**   | HW 레지스터, Pinmux, DRAM 초기화 및 **메모리 방화벽(SCR) 설정 확정** | 잠겨진 방화벽 및 메모리 Carveout 내부에서 **정해진 서비스 API만 처리**        |
| **OS 커널 관계** | 커널 로드 전 실행 완료 $\rightarrow$ **런타임 상호작용 없음**        | 리눅스 커널의 요청(PSCI, SMC, Mailbox)을 받아 **실시간 HW/보안 제어 수행** |

## 3. 단계별 세부 역할

### (1) Boot time mutable FW
1.  **일회성 하드웨어 시동 (Bring-up)**
    *   **MB1 (Microboot 1)**: Pinmux, GPIO, 전압 패드 설정, PMIC 전원 인가, Mem-BCT 기반 SDRAM 초기화 및 메모리 Carveout 분할 수행.
    *   **MB2 (Microboot 2)**: 메인 CPU 코어(CCPLEX)에서 최초 구동되어 상위 펌웨어(ATF, OP-TEE, UEFI)를 스토리지에서 DRAM으로 적재.
2.  **제어권 인계 후 소멸**
    *   초기화 완료 후 제어권을 ATF 및 UEFI로 넘기면 실행을 완전히 마치고 메모리 할당이 해제되거나 비보안 영역으로 반환됩니다.

### (2) Run time FW
1.  **전용 보안 메모리 상주**
    *   MB1이 설정한 하드웨어 방화벽(SCR/TZDRAM)에 의해 일반 OS(리눅스 커널)가 접근할 수 없는 격리 영역(Carveout/SRAM)에 영구 상주합니다.
2.  **런타임 백그라운드 서비스 제공**
    *   **BPMP-FW**: CPU/GPU/DLA 클럭 주파수(DVFS), 전력 도메인 온/오프, SoC 온도 센서 모니터링 담당.
    *   **PSC-FW**: 하드웨어 암호화 키 관리, 런타임 보안 세션 및 서명 검증 서비스를 독립 처리.
    *   **MCE-FW**: CPU 코어 슬립 상태(C-states, Idle), CPU Hotplug 전원 차단 명령 실시간 실행.
    *   **ATF (BL31)**: Secure Monitor로서 커널의 PSCI 호출을 받아 MCE-FW 및 BPMP-FW로 중계.
