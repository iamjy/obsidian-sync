# DLPC347x 컨트롤러 동작 모드 분석

DLPC347x 컨트롤러는 데이터 소스와 표시 방식에 따라 다음과 같은 3가지 운영 모드를 제공합니다.

---

### 1. External Pattern Streaming Mode
> **외부 실시간 데이터 스트리밍 모드**
- **개요**: 외부 비디오 포트를 통해 패턴 데이터를 실시간으로 수신하여 표시합니다.
- **주요 특징**:
    - **데이터 소스**: 외부 장치 (PC, FPGA 등) $\rightarrow$ 컨트롤러
    - **장점**: 실시간 패턴 전송이 가능하여 동적 제어 및 빠른 응답성이 필요한 환경에 적합
    - **참조**: 시스템 구성도 `Figure 1-1` 참조
- **활용 사례**: 3D 광학 검사, 로봇 비전 등

---

### 2. Internal Pattern Streaming Mode
> **내부 플래시 기반 순차 스트리밍 모드**
- **개요**: 컨트롤러 내부 플래시에 저장된 **1D 패턴 데이터**를 순차적으로 표시합니다.
- **주요 특징**:
    - **데이터 소스**: 내부 Flash Memory $\rightarrow$ 디스플레이
    - **장점**: 외부 입력 장치 없이 독립적인 패턴 표시 가능, 시스템 단순화
    - **참조**: 시스템 구성도 `Figure 1-2` 참조
- **활용 사례**: 반복적 동일 패턴 표시, 자동화된 3D 측정 및 인식

---

### 3. Splash Pattern Mode
> **내부 플래시 기반 정지 이미지 모드**
- **개요**: 내부 플래시에 저장된 **2D 이미지 파일**을 고정 패턴으로 표시합니다.
- **주요 특징**:
    - **데이터 소스**: 내부 Flash Memory (2D Image) $\rightarrow$ 디스플레이
    - **특이사항**: `TRIG_IN` 및 `PAT_RDY` 신호를 지원하지 않음 (외부 트리거 없이 동작)
    - **참조**: 시스템 구성도 `Figure 1-2` 참조
- **활용 사례**: 고정 이미지 패턴 표시, 3D 프린팅, 얼굴/지문 인식

---

### 📋 모드별 비교 요약

| 구분 | External Pattern Streaming | Internal Pattern Streaming | Splash Pattern |
| :--- | :---: | :---: | :---: |
| **데이터 소스** | 외부 비디오 포트 | 내부 플래시 (1D) | 내부 플래시 (2D 이미지) |
| **주요 특징** | 실시간/동적 제어 | 반복 패턴/자동화 | 고정 이미지/트리거 없음 |
| **핵심 장점** | 유연한 데이터 변경 | 외부 입력 불필요 | 단순 이미지 출력 |
| **활용 예시** | 3D 검사, 로봇 비전 | 3D 측정 및 인식 | 3D 프린팅, 생체 인식 |
