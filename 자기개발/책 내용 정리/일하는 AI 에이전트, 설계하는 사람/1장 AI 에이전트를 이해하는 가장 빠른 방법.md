인공지능 에이전트의 5가지 핵심 속성


| 속성        | 정의                                       | 없으면 어떻게 되나                 |
| --------- | ---------------------------------------- | -------------------------- |
| 목표 지향성    | 최종 목표를 기준으로 세부 단계를 스스로 구성                | 지시가 없으면 행동하지 못하는 수동적 도구    |
| 자율적 행동    | 각 단계에서 무엇을 할지 스스로 결정                     | 매 단계마다 사람의 명령이 필요한 반자동 시스템 |
| 환경 인식     | 파일 . DB . 웹 . 대화 이력 등 현재 상황을 능동적으로 파악    | 맥락없는 행동으로 엉뚱한 결과 생성        |
| 도구 사용     | 검색 . API . 코드 실행 . 파일 I/O 등 외부 자원에 직접 접근 | 텍스트 생성에만 국한, 실제 업무 처리 불가   |
| 피드백 기반 적응 | 행동 결과를 평가해 다음 행동 수정 ( 자기교정 )             | 오류 발생 시 중단, 반복 실수 교정 불가    |
