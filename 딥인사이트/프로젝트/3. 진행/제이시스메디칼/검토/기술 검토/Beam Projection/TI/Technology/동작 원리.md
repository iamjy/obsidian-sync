## 1. DMD 개요 및 물리적 특성 (Overview & Physical Properties)
- **구성**: 수백만 개의 미세한 반사형 알루미늄 거울로 구성 (최대 800만 개 이상).
- **크기**: 각 거울의 폭은 수 마이크론($\mu m$) 단위.
- **제어 방식**: 정전기적 제어를 통해 초당 수천 번 거울을 기울이거나 전환하여 빛의 방향을 스티어링(Steer).

## 2. 이미지 생성 원리 (Image Generation)
- **기본 메커니즘**: 디지털 비디오 신호와 결합하여 이미지를 생성.
- **픽셀 표현**:
	- **White Pixel**: 빛을 투사 광학계(Projection Optics) 방향으로 반사.
	- **Black Pixel**: 빛을 흡수체(Light Absorber) 방향으로 반사.
	- **Grayscale**: 각 프레임 내에서 빛이 투사 경로로 향하는 시간의 길이에 따라 명암 결정.
- **호환성**: 램프, LED, 레이저 등 다양한 광원 및 가시광선, 적외선(IR), 자외선(UV) 파장 제어 가능.

## 3. 색상 구현 방식 (Color Implementation)
### A. 컬러 휠 방식 (Color Wheel System)
- **구조**: 광원과 DMD 사이에 회전하는 컬러 휠 배치.
- **작동**: RGB 빛이 순차적으로 거울 어레이에 집중될 때, 거울의 전환 타이밍을 휠과 동기화하여 색상 표현. (예: 빨강+초록 $\rightarrow$ 노란색)

### B. 직접 발광 방식 (Direct Colored Source)
- **구조**: 컬러 휠 없이 유색 LED 또는 레이저 광원 사용.
- **특징**: 거울의 전환 속도가 매우 빠르기 때문에 가능하며, 10억 가지 이상의 색상 표현 가능.

## 4. 산업적 응용 (Industrial Applications)
DMD의 고속 픽셀 데이터 처리 능력을 활용하여 다음과 같은 솔루션에 적용:
- **3D 스캐닝**
- **3D 프린팅**
- **센싱 솔루션**

A DMD steer light by electrostatically deflecting or switching each mirror up to thousands of times per second. An image is created when a DMD is combined with a digital video signal. ### An Etendue how-to: A brief introduction to etendue in projection systems

Today we will present a very brief introduction to the optical concept known as etendue and how it can be used when designing projection systems.
( 오늘은 '에탕뒤(etendue)'라고 불리는 광학적 개념과 이것이 투사 ( 프로젝션 ) 시스템 설계에 어떻게 활용되는지에 대해 간략히 소개하겠습니다. )

We will define etendue mathematically, talk about a very important property of etendue, its conservation, and discuss the Etendue of DMDs, and some various projection light sources.
( 먼저 에탕뒤를 수학적으로 정의하고, ==에탕뒤의 매우 중요한 특성인 '보존 법칙'==에 대해 알아본 뒤, DMD 및 다양한 투사 광원의 에탕뒤에 대해 논의하겠습니다. )

Etendue is a geometric property of light that quantifies how much space the light takes up spatially and angularly. Ultimately, it quantifies the throughput capability of the optical system for systems where the light needs to be coupled. Mathematically, it is the product of the area of a source or pupil and the solid angle that the light emitted from that area subtends.
( 에탕뒤는 빛이 공간적, 각도적으로 차지하는 범위를 정량화한 빛의 기하학적 특성입니다. 궁극적으로 이는 빛을 결합 ( coupling ) 해야 하는 광학 시스템에서 빛의 전달 능력 ( throughput ) 을 나타내는 척도가 됩니다. 수학적으로는 광원이나 동공 ( pupil ) 의 면적과, 해당 영역에서 방출되는 빛이 이루는 입체각 ( solid angle ) 의 곱으로 정의됩니다. )

If we assume a circularly symmetric source shown in cross section above, etendue can be simplified to the equation shown. As the area of a light source grows, the etendue grows. And as the solid angle grows, the etendue grows. Etendue has units of length squared.
( 위의 단면도에 나타난 것과 같이 원형 대칭 광원을 가정하면, 에탕뒤는 제시된 식으로 단순화할 수 있습니다. 광원의 면적이 커지면 에탕뒤도 커지며, 입체각이 커져도 에탕뒤는 커집니다. 에탕뒤의 단위는 길이의 제곱 ( length squared ) 입니다. )

And extremely useful and important property of etendue is that it is conserved in a perfect optical system. In the example above, we show an image of a source being formed onto a DMD using a converging lens. At any point in the optical system, etendue can be calculated. And it will never be less than the etendue of the original source.
( ==에탕뒤의 매우 유용하고 중요한 특성 중 하나는 이상적인 광학 시스템에서 그 값이 보존된다는 점==입니다. 위의 예시는 집광 렌즈를 사용하여 광원의 이미지를 DMD 위에 형성하는 과정을 보여줍니다. 광학 시스템 내 어느 지점에서든 에탕뒤를 계산할 수 있으며, 그 값은 결코 원래 광원의 에탕뒤보다 작아지지 않습니다. )

For the example shown, the etendue calculated using the area and cone angle of the image will be greater than or equal to that calculated at the source.
( 제시된 예시에서, 이미지의 면적과 원뿔 각도 ( cone angle ) 를 이용해 계산한 에탕뒤는 광원에서의 에탕뒤보다 크거나 같습니다. )

The light can converge slower, resulting in a smaller half angle and a larger area than the previous case, or the light can converge faster, resulting in a larger half angle and a smaller area. But etendue remains constant.
( 빛이 더 느리게 수렴하여 반각 ( half angle ) 은 작아지고 면적은 커질 수도 있고, 반대로 더 빠르게 수렴하여 반각은 커지고 면적은 작아질 수도 있습니다. 하지만 에탕뒤 값은 일정하게 유지됩니다. )

In practice, etendue does grow due to unintentional or intentional diffusion, scattering, aberrations, and diffraction off of surfaces and through apertures. This is an unavoidable consequence of the use of imperfect elements, and the second law of thermodynamics. But etendue will never decrease.
( 실제 상황에서는 의도적이거나 의도치 않은 확산, 산란, 수차, 그리고 표면이나 조리개 ( aperture ) 에서의 회절 등으로 인해 에탕뒤가 증가합니다. 이는 불완전한 광학 소자의 사용과 열역학 제2법칙에 따른 피할 수 없는 결과입니다. ==그러나 에탕뒤가 감소하는 일은 결코 없습니다==. ) 

Because of this property, the component with the smallest etendue in the system will dictate the throughput of the system. Generally, this is assumed to be the DMD. And a system design is started with this component.
( 이러한 특성 때문에 시스템 내에서 에텐듀 ( etendue ) 값이 가장 작은 구성 요소가 시스템의 광 처리량 ( throughput ) 을 결정==하게 됩니다. 일반적으로 이 구성 요소는 DMD로 간주되며, 시스템 설계는 이 부품을 기준으로 시작됩니다==. )

( ==표에는 시중에서 구할 수 있는 다양한 1080p DMD의 에텐듀 계산 결과가 제시==되어 있습니다. ==조명 콘 ( cone ) 각도는 마이크로미러의 유효 경사각 ( tilt ) 에 의해 결정==되는데, 이는 'ON' 상태의 투사 동공 ( projection pupil ) 으로 '평면 ( flat )' 상태나 'OFF' 상태의 빛이 들어오지 않게 해야 하기 때문입니다. )

The area of the DMD is fixed by the native pixel pitch and resolution and is adjusted with a cosine factor due to the obliquity caused by the required tilted illumination. And finally, the etendue is calculated using the equation described previously.
( ==DMD의 면적은 고유 픽셀 피치와 해상도에 의해 결정되지만, 경사 조명이 필요함에 따른 입사각 ( obliquity ) 영향으로 코사인 ( cosine ) 인자를 적용하여 보정==됩니다. ==최종적으로 앞서 설명한 공식을 사용하여 에텐듀를 계산==합니다. )

As long as it is desirable to capture all of the light, the light source's etendue should not be larger than the DMDs. Some of the most common light sources for projection systems are shown. Lasers generally have the smallest etendue with small emission areas and angles.
( ==모든 빛을 효율적으로 활용하려면 광원의 에텐듀가 DMD의 에텐듀보다 크지 않아야 합니다==. 투사 시스템에 주로 사용되는 광원들의 예가 제시되어 있습니다. 레이저는 일반적으로 발광 면적과 각도가 작아 에텐듀 값도 가장 작습니다. )

Phosphors emit light in a wide Lambertian profile. But because the excitation spot size and shape is controllable, there is some adjustability to the resulting etendue.
( 형광체 ( phosphor ) 는 넓은 램버시안 ( Lambertian ) 분포로 빛을 방출합니다. 하지만 여기 ( excitation )되는 지점의 크기와 모양을 제어할 수 있어, 결과적인 에텐듀 값을 어느 정도 조절할 수 있습니다. )

LEDs also have wide Lambertian emission angles. But the area is dictated by the LED design and fixed by the manufacturer. LEDs generally have a large etendue relative to the other sources.
( LED 또한 넓은 램버시안 방출 각도를 가집니다. 하지만 발광 면적은 LED 설계에 따라 결정되며 제조 단계에서 고정됩니다. LED는 일반적으로 다른 광원에 비해 에텐듀 값이 큽니다. )

A lamp's arc emits light in all directions, and is shaped by the elliptical reflector for use in a projection system. The area emitting the light is actually a volume taken up by the arc plasma. The result is a medium etendue relative to the other available sources.
( 램프의 아크 ( arc ) 는 모든 방향으로 빛을 방출하며, 투사 시스템에 사용하기 위해 타원형 반사경을 통해 빛의 경로가 형성됩니다. 실제 빛을 방출하는 영역은 아크 플라즈마가 차지하는 부피입니다. 그 결과, 다른 광원들과 비교했을 때 중간 정도의 에텐듀 값을 갖게 됩니다. )

Large etendue sources require large lenses and DMDs, and generally result in a higher cost projector. But etendue is just one of the many items to consider when building a system.
( 에텐듀가 큰 광원을 사용하면 대형 렌즈와 DMD가 필요하게 되어, 결과적으로 프로젝터의 비용이 상승하는 경향이 있습니다. 하지만 에텐듀는 시스템을 구축할 때 고려해야 할 여러 요소 중 하나일 뿐입니다. )

The length of the stud is also critical so that the heat sink itself does not interfere with the PCBs the DMD attaches to. More information will need to be understood about the system to optimize this dimension.

### Mounting and Electrical Connection Basics of DMDs

This TI DLP Labs video will cover basic DMD information associated with mechanical design, DMD mounting basics, and DMD electrical interconnects. The details of a specific DMD design will not be covered, but information will guide you to detailed mounting concepts on TI.com. The detailed concepts include assembly and part drawings as well as 3D CAD models. Before covering the DMD mounting information and how to locate the detailed information, it is helpful to understand some basic information about DMDs.
(   이 TI DLP Labs 영상에서는 ==기계적 설계와 관련된 DMD의 기본 정보, DMD 장착 ( mounting ) 의 기초, 그리고 DMD 전기적 상호 연결 ( interconnect )== 에 대해 다룹니다. 특정 DMD 설계의 세부 사항을 직접 다루지는 않지만, TI.com에서 상세한 장착 개념을 확인할 수 있도록 안내해 드립니다. 이러한 상세 개념에는 조립도, ​​부품 도면 및 3D CAD 모델이 포함됩니다. DMD 장착 정보와 상세 정보 확인 방법을 알아보기 전에, DMD에 대한 몇 가지 기본 사항을 이해해 두는 것이 좋습니다. )

The basics include different package styles, typical DMD features, types of electrical interconnects, and what is meant by a package style or family of DMDs. DMDs are available in a wide variety of array sizes, resolutions, and performance characteristics. DMD packages range in sizes to accommodate a 0.2 NHD to a 1.38-inch 4K UHD DMD.
( 기본 사항에는 다양한 패키지 유형, 일반적인 DMD 특징, 전기적 상호 연결 방식, 그리고 DMD 패키지 유형이나 제품군 ( family ) 의 의미 등이 포함됩니다. DMD는 다양한 어레이 크기, 해상도 및 성능 특성으로 제공됩니다. DMD 패키지 크기는 0.2인치 NHD부터 1.38인치 4K UHD DMD까지 다양합니다. )

DMD sizes and resolutions include a 0.47 4K, 0.65 1080p, 0.8 Wide UXGA, 0.95 1080p, and many other sizes and resolutions. The many package styles utilize three types of electrical interconnects. DMDs with board-to-board connectors utilize board-to-board connectors in the system also, DMDs with micro pin grid arrays utilize sockets, and DMDs with land grid arrays utilize interposers.
( DMD 크기와 해상도에는 0.47인치 4K, 0.65인치 1080p, 0.8인치 Wide UXGA, 0.95인치 1080p 등이 있으며, 이 외에도 다양한 규격이 존재합니다. 여러 패키지 유형은 세 가지 방식의 전기적 상호 연결을 사용합니다. 보드 간 ( board-to-board ) 커넥터가 있는 DMD는 시스템에서도 보드 간 커넥터를 사용하며, 마이크로 핀 그리드 어레이 ( micro PGA ) 방식은 소켓을, 랜드 그리드 어레이 ( LGA ) 방식은 인터포저 ( interposer ) 를 사용합니다. )

DMDs do not utilize industry standard packages, and as a result, all except the board-to-board connectors are a custom design. It is worth noting that DMDs with the same series designation are a group or family of DMDs that share common features. DMDs that have the same series designation use the same mounting concepts. Type A DMDs do not share the same common features as those with the same series designation, but have common features within the same ceramic size.
( ==DMD는 업계 표준 패키지를 사용하지 않으므로, 보드 간 커넥터 방식을 제외한 모든 방식은 맞춤형 ( custom ) 설계로 이루어집니다==. 동일한 시리즈 명칭을 가진 DMD들은 공통된 특징을 공유하는 그룹 또는 제품군이라는 점을 참고할 필요가 있습니다. 같은 시리즈 명칭을 가진 DMD들은 동일한 장착 개념을 적용합니다. 'Type A' DMD의 경우, 동일 시리즈 명칭을 가진 다른 제품들과 공통된 특징을 공유하지는 않지만, 동일한 세라믹 크기 내에서는 공통된 특징을 갖습니다. )

DMD features are defined in the mechanical ICD drawing and include the array of micromirrors. The array size depends on the mirror pitch and resolution. The window glass protects the micromirrors. The ceramic base supports the array and incorporates the mounting datums. The location of the array is parallel to a plane established by the datum A features, but does not lie within the plane.
( ==DMD의 특징은 기계적 ICD ( Interface Control Document ) 도면에 정의==되어 있으며, 여기에는 마이크로미러 어레이 ( micromirror array ) 에 대한 내용이 포함됩니다. ==<font color="#d83931">어레이 크기는 미러 피치 ( mirror pitch ) 와 해상도에 따라 결정</font>==됩니다. ==<font color="#d83931">윈도우 글라스 ( window glass ) 는 마이크로미러를 보호하는 역할</font>==을 합니다. ==<font color="#d83931">세라믹 베이스는 어레이를 지지하며 장착 기준점 ( datum ) 을 포함</font>==합니다. ==어레이의 위치는 기준점 A 형상으로 설정된 평면과 평행하지만, 해당 평면 내에 위치하지는 않습니다==. )

The datum A is defined by areas and not visible features on the ceramic. The location of the array in the x, y-axis is defined from datums B and C. In this case, the datums are a hole in a slot. Other DMDs have open slots or defined areas on the edge of the ceramic. The datums A, B, and C are used to position the array in the optics when mounting the DMD.
( ==기준점 A는 세라믹 표면의 특정 영역에 의해 정의되며 눈에 보이는 형상은 아닙니다==. ==X, Y축 방향의 어레이 위치는 기준점 B와 C를 기준으로 정의==됩니다. ==이 경우 기준점은 슬롯 내의 구멍(hole) 형태==입니다. 다른 DMD 모델의 경우 개방형 슬롯이나 세라믹 가장자리에 정의된 영역을 기준점으로 사용하기도 합니다. <font color="#d83931">DMD를 광학계에 장착할 때 기준점 A, B, C를 사용하여 어레이의 위치를 ​​잡습니다</font>. )

The electrical interface defines the area on the back of the DMD where the electrical connection is made. The electrical connection for this DMD utilizes a land grid array. Micro pin grid array and board-to-board connectors are utilized on other DMDs. The thermal interface is an area on the DMD that is contacted directly to cool the DMD. Datums A, B, and C should be used when mounting the DMD for most accurate alignment.
( ==전기적 인터페이스는 DMD 후면에서 전기적 연결이 이루어지는 영역을 의미==합니다. 이 DMD의 전기적 연결에는 LGA(Land Grid Array) 방식이 사용됩니다. 다른 DMD 모델에는 마이크로 PGA(Pin Grid Array)나 보드 간(board-to-board) 커넥터가 사용되기도 합니다. ==열 인터페이스는 DMD를 냉각하기 위해 직접 접촉하는 영역==입니다. ==가장 정확한 정렬을 위해서는 DMD 장착 시 기준점 A, B, C를 활용==해야 합니다. )

Electrical interconnect basics. DMDs with board-to-board connectors mate with connectors that are soldered on a PCB. These connectors have both self-alignment and retention features. DMDs with micro pin grid arrays mate to sockets that are soldered on a PCB. The pins in the DMD self-align to the contacts in the socket.
( 전기적 상호 연결의 기본 사항: 보드 간 커넥터가 있는 DMD는 PCB에 납땜된 커넥터와 결합됩니다. 이 커넥터들은 자동 정렬 및 고정 기능을 갖추고 있습니다. 마이크로 PGA 방식의 DMD는 PCB에 납땜된 소켓과 결합되며, DMD의 핀이 소켓의 접점과 자동으로 정렬됩니다. )

DMDs with LGA pads and open notch-style datums do not have direct alignment between the DMD and the mating interposer. Alignment is accomplished using indirect reference features. The DMD is aligned to the optics chassis and then interposer aligned to the optics chassis. It is important when mounting a DMD with an LGA interconnect to always maintain uniform pressure to ensure a good electrical connection.
( LGA 패드와 개방형 노치 ( notch ) 스타일의 기준점을 가진 DMD는 DMD와 결합되는 인터포저 ( interposer ) 간에 직접적인 정렬이 이루어지지 않습니다. 대신 간접적인 기준 형상을 사용하여 정렬합니다. DMD를 광학 섀시에 정렬한 다음, 인터포저를 광학 섀시에 정렬하는 방식입니다. LGA 인터커넥트를 사용하는 DMD를 장착할 때는 안정적인 전기적 연결을 위해 항상 균일한 압력을 유지하는 것이 중요합니다. )

DMDs with LGA pads and edge-style datums utilize interposers which have features that align the DMD to alignment pins on the interposer. The interposer alignment pins are then used to align the interposer to the PCB. Again, uniform pressure is needed to ensure a good electrical connection. The size of the thermal interface is determined by the opening in the electrical interconnect.
( LGA 패드와 가장자리 ( edge ) 스타일의 기준점을 가진 DMD는 인터포저를 사용하는데, 이 인터포저는 DMD를 인터포저의 정렬 핀에 맞추는 기능을 갖추고 있습니다. 이후 인터포저의 정렬 핀을 사용하여 인터포저를 PCB에 정렬합니다. ==이 경우에도 안정적인 전기적 연결을 위해서는 균일한 압력이 필요==합니다. ==열 인터페이스의 크기는 전기적 상호연결부의 개구부(opening)에 의해 결정==됩니다. )

DMDs with the same series number are considered in the same DMD family and have common features, utilize the same mounting concepts and electrical interconnect. DMDs that share the same series number have the same ceramic size, mounting datums A, B, and C, array center relative to mounting datums A, B, and C, window thickness, illumination direction, thermal interface, electrical interface.
( <font color="#d83931">동일한 시리즈 번호를 가진 DMD는 같은 DMD 제품군으로 분류되며, 공통된 특성을 지니고 동일한 장착 방식 및 전기적 상호연결 구조를 사용</font>합니다. ==동일한 시리즈 번호의 DMD는 세라믹 크기, 장착 기준점(A, B, C), 장착 기준점 대비 어레이 중심 위치, 윈도우 두께, 조명 입사 방향, 열 인터페이스 및 전기적 인터페이스 사양이 모두 동일==합니다. )

The only exception are the automotive DMDs, which are called Series 450, but the array center is not in the same position as the other Series 450 DMDs. DMDs with the same series number can have different array sizes, resolutions, pixel sizes, distance from array to window, and electrical interface and pin signal assignments. Typically, the same optical engine can be used for DMDs in the same family with the only mechanical change needed being a different illumination, integrating tunnel, or rod.
( 유일한 예외는 '시리즈 450 ( Series 450 )'으로 분류되는 차량용 DMD인데, 이 제품들은 다른 시리즈 450 DMD와 어레이 중심 위치가 다릅니다. 동일한 시리즈 번호의 DMD라도 어레이 크기, 해상도, 픽셀 크기, 어레이와 윈도우 간 거리, 전기적 인터페이스 및 핀 신호 할당은 서로 다를 수 있습니다. 일반적으로 동일한 제품군 내의 DMD에는 동일한 광학 엔진을 사용할 수 있으며, 이때 필요한 기구적 변경 사항은 조명계, 인테그레이팅 터널 ( integrating tunnel ) 또는 로드 ( rod ) 를 다르게 적용하는 것뿐입니다. )

The title block on the DMD mechanical ICD drawing indicates the DMD series number and package reference designator. The ICD drawing can be found at the end of the DMD data sheet. The series number of the device is used to identify the detailed mounting concept for a particular DMD. An example is a Series 410 mounting concept will work for all Series 410 DMDs.
( DMD 기구적 ICD ( Interface Control Drawing ) 도면의 표제란에는 DMD 시리즈 번호와 패키지 참조 지정자 ( reference designator ) 가 명시되어 있습니다. 이 ICD 도면은 DMD 데이터 시트의 뒷부분에서 확인할 수 있습니다. 장치의 시리즈 번호는 특정 DMD에 대한 상세 장착 방식을 식별하는 데 사용됩니다. 예를 들어, 'Series 410' 장착 방식은 모든 Series 410 DMD에 적용됩니다. )

DMDs with the same ceramic size share common features, but not to the extent the series family do. The most common ceramic sizes are a 0.7 size and a 0.9 size. Common features within each size include datums A, B, and C and the array center relative to the datums. The same size ceramics do not have the same electrical interface or the number of pins or pad locations.
( ==세라믹 크기가 동일한 DMD들은 공통적인 특징을 공유하지만, 시리즈 제품군 ( family ) 수준의 완전한 공통성을 갖는 것은 아닙니다==. 가장 일반적인 세라믹 크기는 0.7 및 0.9 사이즈입니다. 각 크기 내의 공통 특징으로는 기준면 ( datum ) A, B, C와 이 기준면을 기준으로 한 어레이 ( array ) 중심 위치 등이 있습니다. ==동일한 크기의 세라믹이라도 전기적 인터페이스, 핀 수, 또는 패드 위치가 반드시 동일한 것은 아닙니다==. )

Important considerations when mounting DMDs include alignment of the array, establish and maintain a good electrical connection, control of mechanical forces applied to the electrical and thermal interface areas such that they do not exceed those in the data sheet. The methods to control the mounting loads include by design of features, which is the best and most repeatable. Features of the design are designed to prevent excess loads from being applied to the DMD without relying on assembly process steps.
( ==DMD 장착 시 중요한 고려 사항으로는 어레이 정렬, 양호한 전기적 연결의 확보 및 유지, 그리고 전기 및 열 인터페이스 영역에 가해지는 기구적 힘을 데이터 시트에 명시된 허용 범위를 초과하지 않도록 제어하는 ​​것 등이 있습니다==. ==장착 하중을 제어하는 ​​방법 중 설계적 특징 ( feature ) 을 활용하는 방식이 가장 우수하며 재현성이 높습니다. 이러한 설계 방식은 조립 공정 단계에 의존하지 않고도 DMD에 과도한 하중이 가해지는 것을 방지하도록 설계==됩니다. )

Control of load using an assembly procedure or process will have greater force variation and highly dependent on the person doing the assembly. ( 인터포저의 핀은 광학 섀시의 구멍에 삽입되어 DMD를 광학 부품과 정렬시킵니다. PCB의 구멍은 인터포저의 핀에 맞춰 배치되어 PCB 패드를 인터포저 접점과 정렬시킵니다. DMD, 인터포저, PCB는 숄더 스크류와 코일 스프링을 사용하여 함께 고정되며, 이를 통해 DMD 전기적 인터페이스에 가해지는 하중을 제어합니다. )

The coil spring and gap in which it fits are designed to meet the compression requirements of the interposer contacts without exceeding the maximum limits on the DMD electrical interface area. The coil springs also ensure the load on the electrical interface area is applied uniformly. The clamp provides sufficient stiffness to prevent the PCB from bowing. Bowing of the PCB can result in electrical connection issues.
( 코일 스프링과 스프링이 장착되는 간극은 DMD 전기적 인터페이스 영역의 최대 허용 한도를 초과하지 않으면서 인터포저 접점의 압축 요구 사항을 충족하도록 설계되었습니다. 또한 코일 스프링은 전기적 접촉 부위에 가해지는 하중이 균일하게 전달되도록 합니다. 클램프는 PCB가 휘는 것을 방지할 수 있는 충분한 강성을 제공합니다. PCB가 휘면 전기적 연결 문제가 발생할 수 있습니다. )

The heat sink is secured in place using shoulder screws and coil springs to control the load on the thermal interface area. The coil spring and gap in which it fits are designed to meet the thermal performance requirements without exceeding the maximum loads on the DMD thermal interface. Additional support may be required for large, heavy heat sinks to prevent them from moving during vibration and shock conditions. Any additional support should be done such that the loads on the DMD are not increased above the DMD specifications.
( 히트싱크는 숄더 나사와 코일 스프링을 사용하여 고정되며, 이를 통해 열 인터페이스 영역에 가해지는 하중을 제어합니다. 코일 스프링과 스프링이 장착되는 공간 ( 갭 ) 은 DMD 열 인터페이스의 최대 허용 하중을 초과하지 않으면서 열 성능 요구 사항을 충족하도록 설계되었습니다. 크고 무거운 히트싱크의 경우, 진동이나 충격 상황에서 움직이지 않도록 추가적인 지지 장치가 필요할 수 있습니다. 이러한 추가 지지 장치는 DMD에 가해지는 하중이 DMD 사양을 초과하지 않도록 설치해야 합니다. )

### TI DLP® Display chipset selection guidelines

n this TI DLP Labs training module, we will explore the chipset selection guides for our display products. The TI DLP display and projection chipset selection guide can help product developers select a DLP chipset for display applications by providing an overview of all DLP display chipsets. It contains two sections-- DLP Pico chipsets, which are designed for small form factor, low power display applications. And DLP standard chipsets, designed for high brightness, large screen size display applications.
( 이번 TI DLP Labs 교육 모듈에서는 디스플레이 제품군을 위한 칩셋 선정 가이드를 살펴보겠습니다. TI DLP 디스플레이 및 프로젝션 칩셋 선정 가이드는 모든 DLP 디스플레이 칩셋에 대한 개요를 제공하여, 제품 개발자가 디스플레이 애플리케이션에 적합한 DLP 칩셋을 선택하는 데 도움을 줍니다. 이 가이드는 두 가지 섹션으로 구성되어 있습니다. 하나는 소형 폼 팩터 및 저전력 디스플레이 애플리케이션용으로 설계된 DLP Pico 칩셋이고, 다른 하나는 고휘도 및 대형 화면 디스플레이 애플리케이션용으로 설계된 DLP 표준 칩셋입니다. )

Product developers interested in DLP technology for advanced light control or automotive applications, should visit ti.com/dlp for more information.
( 첨단 광 제어 또는 자동차용 애플리케이션을 위한 DLP 기술에 관심이 있는 제품 개발자라면 ti.com/dlp를 방문하여 더 많은 정보를 확인하시기 바랍니다. )

A display chipset consists of three components-- a digital micrometer device or DMD, a DLP controller, and a dedicated power management IC or PMIC. This selection guide provides helpful references for which combinations of components work together in a given chipset.
( ==디스플레이 칩셋은 DMD ( Digital Micromirror Device ), DLP 컨트롤러, 그리고 전용 PMIC(전력 관리 IC)의 세 가지 구성 요소로 이루어집니다==. 이 선정 가이드는 특정 칩셋 내에서 어떤 구성 요소들이 함께 사용되는지에 대한 유용한 정보를 제공합니다. )

The DMD is a micro electromechanical or MEMS device that modulate light. It can vary in resolution and size. And can contain over 8 million micromirrors, each representing one or more pixels.
( DMD는 빛을 변조하는 MEMS ( 미세 전자기계 시스템 ) 소자입니다. 해상도와 크기는 다양할 수 있으며, 하나 이상의 픽셀을 각각 나타내는 800만 개 이상의 마이크로미러를 포함할 수 있습니다. )

The DLP controller chip is the digital interface between the DMD and the rest of the system. It takes digital input from the front-end receivers, and generates the necessary signals required to display images on the DMD.
( ==DLP 컨트롤러 칩은 DMD와 시스템의 나머지 부분 사이를 연결하는 디지털 인터페이스 역할을 합니다.== 이 칩은 프론트엔드 수신기로부터 디지털 입력을 받아 ==DMD에 이미지를 표시하는 데 필요한 신호를 생성==합니다. )

The PMIC provides all the voltage regulators required by the DMD, DLP controller, and the illumination drivers, like LEDs, laser, and color wheel motor drivers. It also provides monitoring and protection functions.
( ==PMIC는 DMD, DLP 컨트롤러, 그리고 LED, 레이저, 컬러 휠 모터 드라이버와 같은 조명 드라이버에 필요한 모든 전압 레귤레이터 기능을 제공합니다==. 또한 ==모니터링 및 보호 기능도 수행==합니다. )

Each chipset component has its own unique part number to be easily identifiable and differentiated from other parts. The DMD part number consists of a device descriptor-- for example, DLP470TE or DLP470TP-- TI internal numbering, and the package type-- for example, FXJ. Some devices also include both human-readable information and a two-dimensional matrix code.
( ==각 칩셋 구성 요소는 다른 부품과 쉽게 식별하고 구별할 수 있도록 고유한 부품 번호==를 가지고 있습니다. DMD ==부품 번호는 장치 식별자 ( 예: DLP470TE 또는 DLP470TP ), TI 내부 번호, 그리고 패키지 유형 ( 예: FXJ ) 으로 구성==됩니다. 일부 장치에는 사람이 읽을 수 있는 정보와 2차원 매트릭스 코드가 모두 포함되기도 합니다. )

The controller part number and packaging size is similar to the DMD part number, with each DLP controller having the DLP device name followed by the TI part number. Typically, a DLP controller part number starts with DLP followed by C, which stands for controller. The digits following the C identify the unique controller part number.
( 컨트롤러 부품 번호 및 패키지 크기 체계는 DMD 부품 번호와 유사하며, 각 DLP 컨트롤러는 DLP 장치 이름 뒤에 TI 부품 번호가 붙는 형태를 띱니다. ==일반적으로 DLP 컨트롤러 부품 번호는 'DLP'로 시작하고 그 뒤에 컨트롤러를 의미하는 'C'가 붙습니다. 'C' 뒤에 오는 숫자는 해당 컨트롤러의 고유 부품 번호를 나타냅니다==. )

The package size is the physical length and width of the device, measured from corner to corner. For example, DLPC3430, which is 7 by 7 millimeter squared.
( 패키지 크기는 장치의 물리적 가로 및 세로 길이로, 모서리에서 모서리까지를 기준으로 측정합니다. 예를 들어, DLPC3430은 7 x 7mm 크기입니다. )

The PMIC part number consists of DLP followed by A, which indicates that the part is a PMIC. The digits following the A identify the unique part number. For more information, see the device marking section of the data sheet of the product you are interested in.
( ==PMIC 부품 번호는 'DLP' 뒤에 'A'가 붙는 형태로 구성되며, 여기서 'A'는 해당 부품이 PMIC임을 나타냅니다. 'A' 뒤에 오는 숫자는 고유한 부품 번호를 식별합니다==. 자세한 내용은 관심 있는 제품의 데이터시트 중 장치 마킹 ( device marking ) 섹션을 참조하십시오. )

The micromirror orientation is the orientation of each mirror relative to the DMD package. For the square orientation, the micromirror edges are parallel to the DMD package edges. For a diamond orientation, the micromirror edges are rotated 45 degrees relative to the DMD package edges.
( ==마이크로미러 방향 ( orientation ) 은 DMD 패키지를 기준으로 한 각 미러의 방향을 의미합니다==. 정사각형 ( square ) 방향의 경우, 마이크로미러의 가장자리가 DMD 패키지의 가장자리와 평행합니다. 다이아몬드 ( diamond ) 방향의 경우, 마이크로미러의 가장자리가 DMD 패키지의 가장자리를 기준으로 45도 회전된 상태입니다. )

In a DLP system, the display resolution is a function of the number of mirrors on the DMD. Each mirror can represent one or more pixels of the displayed image. Resolution is the number of pixels that can be displayed on the screen. And it is measured by the number of horizontal pixels in each row and the number of vertical pixels in each column. DLP display resolutions range from 640 by 360, or NDH, to 3840 by 2160, or 4K UHD.
( ==DLP 시스템에서 디스플레이 해상도는 DMD에 있는 미러의 수에 따라 결정됩니다==. 각 미러는 표시되는 이미지의 픽셀을 하나 이상 표현할 수 있습니다. 해상도는 화면에 표시할 수 있는 픽셀의 수를 의미하며, 각 행의 가로 픽셀 수와 각 열의 세로 픽셀 수로 측정됩니다. DLP 디스플레이 해상도는 640 x 360 ( nHD ) 부터 3840 x 2160 ( 4K UHD ) 까지 다양합니다. )

The micrometer pitch is the distance between two micromirrors measured from the center of one micromirror to the center of another micromirror vertically or horizontally in micrometers. The micromirror array diagonal size is the size of the micromirror array measured diagonally in inches. Depending on the DMD, the diagonal size varies between 0.2 inch and 0.66 inch.
( ==마이크로미러 피치 ( pitch ) 는 두 마이크로미러 사이의 거리로, 한 마이크로미러의 중심에서 다른 마이크로미러의 중심까지 수직 또는 수평 방향으로 측정한 값 ( 단위: 마이크로미터 ) 입니다==. 마이크로미러 어레이 대각선 크기는 마이크로미러 어레이를 대각선 방향으로 측정한 크기 ( 단위: 인치 ) 입니다. DMD에 따라 대각선 크기는 0.2인치에서 0.66인치 사이로 다양합니다. )

The DMD part number incorporates the array diagonal. For example, the 0.66 inch diagonal size DMD has the part number DLP660TE. The DMD package size is the height and width of the entire DMD package. Typically, the smaller the micrometer array diagonal size, the smaller the DMD package size.
( ==DMD 부품 번호에는 어레이 대각선 크기 정보가 포함됩니다. 예를 들어, 대각선 크기가 0.66인치인 DMD의 부품 번호는 DLP660TE입니다==. DMD 패키지 크기는 전체 DMD 패키지의 가로 및 세로 길이를 의미합니다. 일반적으로 마이크로미러 어레이의 대각선 크기가 작을수록 DMD 패키지 크기도 작아집니다. )

Illumination direction is the orientation of the illumination path relative to the micromirror array. The DMD can be illuminated from the side, bottom, or corner depending on the micromirror design.
( ==조명 방향 ( illumination direction ) 은 마이크로미러 어레이를 기준으로 한 조명 경로의 방향을 의미합니다==. DMD는 마이크로미러 설계에 따라 측면, 하단 또는 모서리 방향에서 빛을 조사할 수 있습니다. )

Brightness is the amount of visible light emitted from a projector or projection system. It is measured in anti-lumens, and is independent of image size. With TI DLP technology, it is possible to create projectors spanning a broad brightness range, from 30 lumens for projectors embedded into products like smartphones or tablets, to over 10,000 lumens for large venue projectors.
( ==밝기란 프로젝터나 프로젝션 시스템에서 방출되는 가시광선의 양을 의미합니다. 이는 루멘 ( lumen ) 단위로 측정==되며, 이미지 크기와는 무관합니다. TI DLP 기술을 활용하면 스마트폰이나 태블릿 같은 기기에 내장되는 30루멘급 프로젝터부터 대형 공연장용 10,000루멘 이상급 프로젝터에 이르기까지, 폭넓은 밝기 범위를 아우르는 프로젝터를 구현할 수 있습니다. )

Image diagonal size is the recommended maximum screen size for each projector, measured diagonally in order to maintain constant image brightness or nits. The image diagonal size depends on the projector lumens capability or brightness. Typically, the image diagonal size scales with projector brightness capability.
( ==이미지 대각선 크기는 일정한 이미지 밝기 ( 니트, nits ) 를 유지하기 위해 설정된 각 프로젝터의 권장 최대 화면 크기를 의미합니다==. 이 크기는 프로젝터의 루멘 성능, 즉 밝기에 따라 결정됩니다. 일반적으로 이미지 대각선 크기는 프로젝터의 밝기 성능에 비례하여 결정됩니다. )

Illumination power consumption is the amount of power the illumination source uses while it is turned on. The table lists the maximum amount of current supported by each PMIC. Typically, higher current means higher brightness capability. The appropriate PMIC should be selected based on the illumination type and brightness needed.
( ==조명 전력 소비량은 조명 광원이 켜져 있을 때 사용하는 전력량을 의미합니다. 표에는 각 PMIC가 지원하는 최대 전류량이 나열되어 있습니다==. 일반적으로 전류량이 높을수록 더 높은 밝기를 구현할 수 있습니다. 따라서 조명 유형과 필요한 밝기에 맞춰 적절한 PMIC를 선택해야 합니다. )

The frame refresh rate is measured in hertz, and it is simply the number of frames displayed each second. Typically, the higher the refresh rate, the smoother, cleaner, and sharper the video appears. DLP IntelliBright algorithms consist of a suite of image-processing algorithms, local area brightness boost or LABB, and content adaptive illumination control or CAIC.
( ==프레임 재생률 ( refresh rate ) 은 헤르츠 ( Hz ) 단위로 측정되며, 이는 초당 표시되는 프레임 수를 나타냅니다==. 일반적으로 재생률이 높을수록 영상이 더 부드럽고 깨끗하며 선명하게 보입니다. DLP IntelliBright 알고리즘은 일련의 이미지 처리 알고리즘으로 구성되는데, 여기에는 국소 영역 밝기 향상 ( LABB ) 과 콘텐츠 적응형 조명 제어 ( CAIC ) 가 포함됩니다. )

Keystone correction is used when the optical axis of a projection system is not perpendicular to the screen, resulting in a geometrically distorted image. The keystone distortion can be corrected optically, which is very difficult, cost prohibitive, and is not adjustable or by image processing. DLP controllers provide keystone correction by remapping the input image to the DMD array in such a way as to produce a rectangular image at the screen.
( ==키스톤 보정은 프로젝션 시스템의 광축이 스크린과 수직을 이루지 않아 이미지가 기하학적으로 왜곡될 때 사용됩니다==. 키스톤 왜곡은 광학적으로 보정할 수도 있지만, 이는 매우 어렵고 비용이 많이 들며 조정이 불가능하다는 단점이 있습니다. ==반면 이미지 처리를 통한 보정 방식에서는 DLP 컨트롤러가 입력 이미지를 DMD 어레이에 재매핑하여 스크린에 직사각형 이미지가 표시되도록 합니다==. )

DLP standard chipsets are designed for display applications that demand the highest brightness and performance. Example applications include laser TV, digital signage, and business and education displays, among others. ### TI DLP® DMD datasheet optical terminology overview

In this TI DLP Labs training module, we will cover some of the common optical terms found in DLP Digital Micromirror Device, or DMD, datasheets. DLP DMDs are qualified over a specific wavelength range. Standard display DMDs assume a white light spectrum where the light is between 420 and 700 nanometers. Operating the DMD outside this range can lead to a reduced lifetime. DLP also has specific DMDs that use illumination sources in the Ultraviolet, or UV, and Near-Infrared, or NIR, range.
( 이번 TI DLP Labs 교육 모듈에서는 DLP DMD ( Digital Micromirror Device ) 데이터시트에서 흔히 볼 수 있는 광학 용어들을 다룹니다. DLP DMD는 특정 파장 범위 내에서 사용하도록 검증되었습니다. 표준 디스플레이용 DMD는 420~700나노미터 ( nm ) 범위의 백색광 스펙트럼을 기준으로 합니다. 이 범위를 벗어나 DMD를 작동하면 수명이 단축될 수 있습니다. 또한 DLP는 자외선 ( UV ) 및 근적외선 ( NIR ) 범위의 조명 광원을 사용하는 특수 DMD 제품군도 제공합니다. )

It is important to note that different light sources have unique thermal loads for a given lumens value. Lamps, LEDs, and laser phosphor sources provide a heat load of approximately 310 lumens per watt. With the increased usage of RGB direct lasers, the laser spectrum is 230 lumens per watt, which increases the thermal load on the DMD. For specific information on this topic, watch the Thermal Management of DMDs DLP Labs module linked immediately below this video.
( 광원마다 동일한 루멘 ( lumen ) 값에 대해 발생하는 열 부하가 다르다는 점을 유의해야 합니다. 램프, LED, 레이저 형광체 ( laser phosphor ) 광원은 와트당 약 310루멘의 열 부하를 발생시킵니다. 최근 RGB 직접 레이저 ( direct laser ) 의 사용이 증가함에 따라 레이저 스펙트럼은 와트당 230루멘 수준이 되며, 이는 DMD에 가해지는 열 부하를 증가시킵니다. 이 주제에 대한 자세한 내용은 이 영상 바로 아래에 링크된 'DMD의 열 관리 ( Thermal Management of DMDs ) ' DLP Labs 모듈을 참조하십시오. )

The diagram above shows illumination of a 12-degree tilt as well as a 17-degree tilt device. Marginal ray is defined as the widest angle from normal of the illumination design. For a standard telecentric design, the following applies. Using our 17-degree tilt device, the marginal ray is the sum of 34-degree illumination angle plus the 17-degree half-angle cone of an F/1.7 design. The specifications for this device defines the max allowable as 55 degrees. Keeping the light bundle less than 55 degrees will prevent shadowing due to the window aperture.
( 위 다이어그램은 12도 틸트 ( tilt ) 및 17도 틸트 소자에 대한 조명 상태를 보여줍니다. 한계 광선 ( marginal ray ) 은 조명 설계상 법선 ( normal ) 을 기준으로 가장 넓은 각도로 정의됩니다. 표준 텔레센트릭 ( telecentric ) 설계의 경우 다음 사항이 적용됩니다. 17도 틸트 소자를 사용할 때, 한계 광선은 34도의 조명 각도와 F/1.7 설계의 17도 반각 원뿔 ( half-angle cone ) 을 합친 각도가 됩니다. 해당 소자의 사양에서는 최대 허용 각도를 55도로 규정하고 있습니다. 광속 ( light bundle ) 을 55도 미만으로 유지하면 윈도우 개구부 ( window aperture ) 로 인한 음영 ( shadowing ) 현상을 방지할 수 있습니다. )

Non-telecentric designs illuminate the device at angles higher than 2x the tilt angle. It is recommended to model the DMD and window apertures to ensure that light rays incident on the active array clear the window aperture on the incoming light side.
( 비텔레센트릭 ( non-telecentric ) 설계에서는 틸트 각도의 2배를 초과하는 각도로 소자에 빛을 조사합니다. 따라서 DMD와 윈도우 개구부를 모델링하여, 활성 어레이 ( active array ) 로 입사되는 광선이 입사 측 윈도우 개구부에 걸리지 않고 통과하는지 확인하는 것이 권장됩니다. )

The DMD mirror array is composed of active addressable mirrors that rotate from on state to off state. For the sample DLP4710 DMD shown, the tilt angle is plus or minus 17 degrees. There is a border of non-addressable mirrors surrounding the active array called the Pond Of Mirrors, or POM. They are landed in the off state to provide a black transition border to the active array.
( DMD 미러 어레이는 ON 상태와 OFF 상태로 회전하는 활성 어드레싱 가능 미러 ( active addressable mirrors ) 로 구성됩니다. 예시로 제시된 DLP4710 DMD의 경우, 틸트 각도는 ±17도입니다. 활성 어레이 ( active array ) 주변에는 'Pond Of Mirrors ( POM )' 라고 불리는, 개별적으로 제어되지 않는 ( non-addressable ) 거울 영역이 있습니다. 이 거울들은 활성 어레이에 검은색 전이 경계 ( black transition border ) 를 제공하기 위해 'off' 상태로 고정됩니다. )

DMD pixel designs offer three different illumination directions depending on the device-- bottom, side, and corner. The 5.4-micron pitch devices have a 17-degree tilt angle. The illumination options are designed for optimum efficiency while providing the smallest optical volume possible.
( DMD 픽셀 설계는 장치에 따라 하단 ( bottom ), 측면 ( side ), 모서리 ( corner ) 의 세 가지 조명 입사 방향을 지원합니다. 5.4마이크론 피치 장치의 경우 17도의 틸트 ( 기울기 ) 각도를 가집니다. 이러한 조명 옵션은 최적의 효율을 내는 동시에 광학계의 부피를 최소화하도록 설계되었습니다. )

Total transmission through the windows is calculated by the square of 97% transmittance or 94% transmission. The coding transmission will roll off outside the visible range. Our UV and NIR devices have window transmissions optimized for those applications.
( 윈도우를 통과하는 전체 투과율은 97% 또는 94% 투과율의 제곱으로 계산됩니다. 투과율은 가시광선 범위를 벗어나면 감소 ( roll-off ) 하는 특성을 보입니다. UV 및 NIR용 장치는 해당 응용 분야에 최적화된 윈도우 투과 특성을 갖추고 있습니다. )

There are many options for an optical design. It is recommended to start with a telecentric projection design and set the illumination and projection F number to match the F number as defined by the tilt angle of the device. For example, a 17-degree device will have an F number of F/1.7 and an illumination angle of 34 degrees. These choices should eliminate flat-state light artifacts and provide a pupil-matched system design.
( 광학 설계에는 다양한 옵션이 존재합니다. 텔레센트릭 ( telecentric) 투사 설계를 기본으로 하고, 장치의 틸트 각도에 따른 F-넘버 ( F-number ) 에 맞춰 조명 및 투사 F-넘버를 설정하는 것이 권장됩니다. 예를 들어, 17도 장치의 경우 F-넘버는 F/1.7, 조명 입사각은 34도가 됩니다. 이러한 설정을 통해 평면 상태 ( flat-state ) 에서 발생하는 빛에 의한 아티팩트 ( artifact ) 를 제거하고, 동공이 일치하는 ( pupil-matched ) 시스템을 설계할 수 있습니다. )

Controlling illumination overfill is important for increasing the optical efficiency, reducing thermal loads, and eliminating window-induced optical artifacts. Full system design examples are available on TI.com and in the link below this video.
( 조명 오버필 ( illumination overfill ) 을 적절히 제어하는 ​​것은 광학 효율을 높이고, 열 부하를 줄이며, 윈도우로 인한 광학적 아티팩트를 제거하는 데 중요합니다. 전체 시스템 설계 예시는 TI.com 및 이 영상 하단의 링크에서 확인하실 수 있습니다. )
