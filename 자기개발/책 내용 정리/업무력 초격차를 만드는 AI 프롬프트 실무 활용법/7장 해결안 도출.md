## 새로운 조합을 통해 해결안을 만드는 방법

SCAMPER는 이미 존재하는 방식, 제도, 아이디어를 대상으로 의도적으로 질문을 던져 변경하는 도구다. 핵심은 간단하다. 아이디어를 평가하지 말고, 흔들어서 다른 모습이 나올 수 있는지를 보는 것이다.

SCAMPER는 다음 7가지 질문으로 구성된다.
1) Substitute ( 대체 ) : 
2) Combine ( 결합 )
3) Adapt ( 응용 )
4) Modify ( 변형 )
5) Put to another use ( 전용 )
6) Eliminate ( 제거 )
7) Reverse ( 전환 )
