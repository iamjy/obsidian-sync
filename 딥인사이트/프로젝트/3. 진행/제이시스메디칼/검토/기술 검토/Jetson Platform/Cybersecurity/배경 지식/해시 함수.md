## 해시 함수란?

해시 함수의 역할은 <font color="#de7802">모든 것에 고유한 식별자를 붙이는 것</font>이다.

> Note: 해시 함수의 출력을 <font color="#de7802">다이제스트 ( digest )</font>, 또는 해시라고 한다.

해시 함수는 **임의의 길이의 입력을 받아 고정된 길이 출력 ( 예: SHA-256의 경우 256비트 ) 을 생성**한다. 동일한 입력을 해시하면 동일한 다이제스트가 생성된다.

## 해시 함수의 보안 속성

응용 암호학에서 해시 함수는 세 가지 보안 속성을 제공하기 위해 정의된 구조다.

1. <font color="#de7802">역상 저항성</font>:
   주어진 출력을 입력으로 바꾸는 역함수를 누구도 만들 수 없는 성질이다.
   ![[Pasted image 20261019130142.png]]
   그림 2.3) 해시 함수 ( 그림에서 믹서기로 표현 ) 에 의해 생성된 다이제스트가 주어졌을 때, 사용된 원래 입력을 해시 함수로 찾는 것은 불가능 하다 ( 또는 기술적으로 너무 어려워서 사실상 불가능 하다 ).
   
2. <font color="#de7802">제2역상 저항성</font>:
   입력과 입력에 해당하는 다이제스트가 주어졌을 때 해당 다이제스트를 생성하는 다른 입력을 찾을 수 없다는 뜻이다.
   ![[Pasted image 20261019130426.png]]
   그림 2.4) 입력과 입력에 해당하는 다이제스트가 주어졌을 때 해당 다이제스트를 생성하는 다른 입력을 찾을 수 없다.
   
3. <font color="#de7802">충돌 저항성</font>:
   아무도 동일한 출력을 만드는 두 개의 다른 입력을 생성할 수 없도록 보장한다.
   ![[Pasted image 20261019130845.png]]
   그림 2.5) 동일한 출력값을 발생시키는 두 개의 입력을 찾을 수 없다.

충돌 저항성과 제2역상 저항성이 구분이 잘 안될 수 있다. 둘의 차이점을 잘 생각해보자.

## 해시 함수의 보안 제약

보안 속성은 그 자체로는 의미가 없다. 보안 속성은 해시 함수를 어떻게 사용하냐에 따라 의미를 가진다.

<font color="#de7802">다이제스트의 크기가 중요</font>하다. 이는 결코 해시 함수만의 특성이 아니다. 모든 암호학 알고리즘에서 파라미터의 크기는 중요한 요소다. <font color="#de7802">해시 함수가 실제로 생성해야 하는 최소 출력 크기는 256비트</font>다. 이는 상당한 길이의 출력이기에 컴퓨터의 역사에서 한 획을 긋는 획기적인 사건이 발생하지 않는 한 충돌에 도달할 수 없다.
그럼 이 256비트는 어떻게 나온 수일까? <font color="#de7802">실제 암호학에서 알고리즘은 최소 128비트의 보안을 목표</font>로 한다.이는 알고리즘을 깨고자 하는 공격자가 약 2의128승회의 작업을 수행해야 함을 의미한다. 128비트의 보안이 목표로 하는 숫자라면 해시 함수도 최소한 256비트 출력을 제공해야 한다.

<font color="#de7802">128비트 보안을 달성하려면 최소한 다음과 같은 다이제스트 길이가 필요</font>하다.

- <font color="#de7802">충돌 저항성을 위해서는 256비트</font>
- <font color="#de7802">역상 저항성 및 제2역상 저항성을 위해서는 128비트</font>

## 해시 함수의 실사용

해시 함수는 보통 단독으로 쓰이지 않는다. 보통 다른 요소와 결합하여 암호학 프리미티브, 또는 암호학 프로토콜을 구성한다.

>Note: 암호학 프리미티브
> 안전한 보안 시스템과 프로토콜을 구축하기 위해 가장 기본적은 저수준의 알고리즘이나 함수 ( 기본 요소 ) 를 의미한다. 레고 블록에 비유하면,거대한 성 ( 보안 프로토콜 ) 을 만들기 위해 사용되는 가장 기본적인 단위 블록과 같다. 

## 표준화된 해시 함수

CRC32 와 같은 함수는 암호화 해시 함수가 아니라 오류 감지 코드 함수다. 해시 함수와는 혼동하지 않아야 한다. CRC32 의 출력은 보통 체크섬이라 부른다.

**MD5 및 SHA-1**:
MD5 및 SHA-1과 같은 유명한 해시 함수는 오늘날에는 뚫린 것으로 보고 있다. 이러한 해시 함수가 깨진 이유는 컴퓨터 성능의 발달 덕이기도 하지만 근본적으로는 해시 함수의 설계 방식 자체에서 결함이 발견되었기 때문이다. 그럼에도 알고리즘의 역상 저항성에만 의존하고 충돌 저항성에는 의존하지 않는 시스템에서 MD 및 SHA-1을 사용하는 사람들이 여전히 있다.

<font color="#de7802">SHA-2</font>:
가장 널리 사용되는 해시 함수 중 하나이자, **가장 널리 채택된 해시 함수**이다.
**NSA 에서 발명**하고 2001년 **NIST 에서 표준화**했다. 

<font color="#de7802">오늘날 주로 쓰이는 것은 SHA-256</font> 이다. SHA-256 은 <font color="#de7802">세 가지 보안 속성에 필요한 최소 128 비트의 보안을 제공</font>한다. 보안에 더 엄격한 애플리케이션은 SHA-512 를 사용한다.

SHA-2 에는 4가지 다른 버전이 있고 각각 <font color="#de7802">224, 256, 384, 512 비트의 출력 생성</font>한다. 각각의 공식 이름은 다음과 같다.

- <font color="#de7802">SHA-224</font>
- <font color="#de7802">SHA-256</font>
- <font color="#de7802">SHA-384</font>
- <font color="#de7802">SHA-512</font>
- <font color="#de7802">SHA-512/224</font>: SHA-512 의 결과를 잘라서 224 비트 출력을 제공
- <font color="#de7802">SHA-512/256</font>:  SHA-512 의 결과를 잘라서 256 비트 출력을 제공
