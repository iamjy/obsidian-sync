### 세션이란

💡모든 세션의 대화 기록은 '~/.claude/projects/{프로젝트 경로}' 디렉터리 아래에 '세션ID 명의 .json' 파일로 저장됩니다.

>**Note: 세션을 짧게 유지하는 습관을 들여야 한다.**
>  한 세션에 모든 것을 욱여넣으면 컨텍스트가 빠르게 찬다.
>  '작업의 최소 단위'를 한 세션으로 처리하고, 다음 작업은 새 세션을 여는 방식이 비용/시간 측면에서 효율적이다.

---
### 컨텍스트에 파일 추가하기

```
@src/login.tx 이 파일에 입력 검증 로직이 어디 있는지 찾아줘
```

```
@src/components/ 이 폴더의 컴포넌트들 모두 보안 문제 없는지 확인해 줘.
```

>Note: 파일을 명시하면 클로드 코드의 집중도가 높아진다.
> "이 파일 봐 줘."와 "프로젝트 전체에서 관련 파일 찾아봐 줘."는 결과 품질이 다릅니다.
> 작업 범위가 명확할 때는 @로 파일을 지정하는 습관을 들이면 좋습니다.
